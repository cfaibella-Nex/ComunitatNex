Accessibilitat

Volem que aquesta web la pugui fer servir tothom, i especialment les persones grans i les persones amb dificultats visuals, motores o cognitives.

Criteris que seguim

La web s'ha dissenyat inspirant-se en les pautes WCAG 2.2 nivell AA del W3C i en la norma europea EN 301 549 d'accessibilitat dels productes i serveis digitals. Les revisem cada vegada que afegim continguts o funcions noves.

Què hi trobaràs

  • Lletra gran de base i botons A− / A+ a dalt de tot per fer-la encara més gran. La web recorda la mida que triïs.
  • Colors amb bon contrast entre el text i el fons.
  • Botons grans, fàcils de tocar amb el dit.
  • Es pot navegar amb el teclat, i sempre es veu on és el cursor.
  • Les imatges tenen descripció per a lectors de pantalla.
  • Si tens configurat el dispositiu per reduir les animacions, la web ho respecta.
  • Per apuntar-te no cal crear cap compte: només el nom i el telèfon.
  • Sempre tens el telèfon a la vista, per si prefereixes apuntar-te trucant.
  • La web està en català i castellà.

Si alguna cosa no et funciona

Si trobes cap dificultat, digues-nos-ho i t'ajudarem per una altra via: escriu a infonex@nexsocial.org o truca al 660 435 871.

Última revisió: 27 de setembre de 2026.

Accesibilidad

Queremos que esta web la pueda usar todo el mundo, y especialmente las personas mayores y las personas con dificultades visuales, motoras o cognitivas.

Criterios que seguimos

La web se ha diseñado inspirándose en las pautas WCAG 2.2 nivel AA del W3C y en la norma europea EN 301 549 de accesibilidad de los productos y servicios digitales. Las revisamos cada vez que añadimos contenidos o funciones nuevas.

Qué encontrarás

  • Letra grande de base y botones A− / A+ arriba del todo para hacerla aún más grande. La web recuerda el tamaño que elijas.
  • Colores con buen contraste entre el texto y el fondo.
  • Botones grandes, fáciles de pulsar con el dedo.
  • Se puede navegar con el teclado, y siempre se ve dónde está el cursor.
  • Las imágenes tienen descripción para lectores de pantalla.
  • Si tienes configurado el dispositivo para reducir las animaciones, la web lo respeta.
  • Para apuntarte no hace falta crear ninguna cuenta: solo el nombre y el teléfono.
  • Siempre tienes el teléfono a la vista, por si prefieres apuntarte llamando.
  • La web está en catalán y castellano.

Si algo no te funciona

Si encuentras alguna dificultad, dínoslo y te ayudaremos por otra vía: escribe a infonex@nexsocial.org o llama al 660 435 871.

Última revisión: 27 de septiembre de 2026.
